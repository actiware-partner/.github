# ACTIWARE.IO für Partner

Hier finden Sie den Einstieg in den Betrieb und die Erweiterung von ACTIWARE.IO. Die Plattform verbindet Prozessautomatisierung, Dokumentenverarbeitung, Systemintegration und KI. Einen Überblick über Funktionen und Einsatzbereiche finden Sie auf der [Produktseite von ACTIWARE.IO](https://www.actiware.de/actiware-io).

## Betrieb und Entwicklung

- [ACTIWARE.IO mit Docker bereitstellen](https://github.com/actiware-partner/actiware-io-docker) – Docker-Compose-Dateien, Beispielkonfigurationen und Anleitungen zur Einrichtung.
- [Eigene Module entwickeln](https://github.com/actiware-partner/actiware-io-module-example) – C#-Beispiele für Prozessoren und Formatierungsfunktionen als Ausgangspunkt für eigene Module.
